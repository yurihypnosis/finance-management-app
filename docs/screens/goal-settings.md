# 目標設定 — 画面別改善戦略

## この画面が答える質問
**「3つの目標(残すお金・支出・投資)をいくらに設定する?」**

## 現状の問題
- 構成はシンプルで大きな問題はないが、スライダーのみの入力で細かい金額が設定できない(step 5,000〜10,000円固定・範囲外は入力不可)。
- 各目標の進捗バー・メッセージが表示されるが、これは「設定」ではなく「現状」の情報で役割が混ざっている。
- 「ホームへ戻る」リンクなどヘッダーが独自作り。

## 改善戦略

1. **1目標=1カード**: 目標名+現在値(大きめ)+スライダー+数値入力の併用。タップで直接入力できることを最優先。
2. **現状フィードバックは1行に**: 「今月は達成ペース」「あと◯円」程度の1行だけ残し、進捗の詳細は各画面(ホーム/支出/投資)に任せる。
3. ヘッダー・戻る導線は共通 ScreenHeader(戻る矢印)に統一。
4. 変更は即保存(現状どおり)だが、保存インジケータは実データ変更時のみ点灯(appStore の PERSISTED_KEYS 対応済み)。

## この画面から出て行く情報
- 各目標の詳細な進捗メッセージ → それぞれの利用画面へ
