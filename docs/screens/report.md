# レポート — 画面別改善戦略

## この画面が答える質問
**「先月までと比べて、支出はどう変化している?」**

## 現状の問題
- 画面名「レポート・統計」とナビ「レポート」が不一致。
- 平均/最小/最大/**標準偏差**の4列テーブル、「n=◯ヶ月」「80%信頼区間」など統計用語が生で露出。モバイル家計簿の言葉ではない。
- 唯一の棒グラフが高さ90px・ラベル10pxで補助的。内訳が文字リスト+2pxバー。
- 前月比・カテゴリ別統計・現金統計が同格に縦積みで、読み通す構成になっている。

## 改善戦略

### 情報の階層
1. **ヒーロー: 前月比** — 「先月より +1.2万円」を大数字+増減色(増=red系/減=green)で先頭に。矢印 or 小さなスパークラインを添える。
2. **推移グラフの主役化** — 月別棒グラフを高さ160px以上に拡大し、当月ハイライト+タップで月選択(MonthSwitcher と連動)。金額ラベルは選択月のみ表示。
3. **内訳の視覚化** — ランキングリストをドーナツ(または100%積み上げバー)+上位カテゴリの色付きリストに置き換え。カテゴリ色は予算画面と共通。
4. **統計は「ふつうの言葉」+詳細折りたたみ** — 初期表示は「食費は平均より +3,000円 使いすぎ」型の1行インサイトのみ。平均/最小/最大/標準偏差のテーブルと信頼区間は「詳しい統計を見る」の折りたたみ(または詳細シート)へ移動。用語は「いつもの月なら ◯〜◯円」のように翻訳する。

### ビジュアル
- グラフ実装は Phase 1 のチャート基礎コンポーネント(SVGベースで依存追加なし)を使用。
- 前月比のカテゴリ別増減は増減量順の上位3件だけ表示し、残りは折りたたみ。

## この画面から出て行く情報
- 標準偏差・n値・信頼区間の生表示 → 折りたたみ詳細へ(削除はしない)
- 現金支出の統計 → 同じ折りたたみ詳細に統合
