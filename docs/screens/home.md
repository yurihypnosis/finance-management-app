# ホーム — 画面別改善戦略

## この画面が答える質問
**「今月、あといくら残せる?」** — アプリを開いた3秒でこれだけが伝われば成功。

## 現状の問題
- 1画面に7ブロック(ヒーロー+内訳バー+凡例+コーチメッセージ+貯蓄目標+超過アラート+超過カテゴリリスト+「このさき」タイル)が縦積みで、主役が埋もれている。
- 内訳バーが2pxで凡例テキストを読まないと意味が取れない。
- 貯蓄目標・コーチメッセージ・超過リストがすべて同格の文字情報として並ぶ。
- タイトル行の作りが他画面と異なる(`row-flex` + padding上書き)。

## 改善戦略

### 情報の階層(上から)
1. **ヒーロー: 残せるお金** — 現状維持だが唯一の大数字とする。手取り内訳のバーは太い積み上げバー(固定費/変動費/残り)に格上げし、凡例はバー内 or 直下に色チップ+短ラベルで統合。
2. **貯蓄目標の達成状況** — 独立ブロックをやめ、ヒーロー直下の1行リング(または進捗バー+パーセント)に圧縮。詳細・編集は目標設定画面へ。
3. **今月の注意(条件表示)** — 予算超過があるときだけ、超過額とカテゴリ数を1枚のアラートカードで表示 → タップで予算画面へ。**超過カテゴリの全リストはホームから撤去**(予算画面の仕事)。
4. **ショートカットタイル(このさき)** — ライフイベント・投資の2タイルは維持するが、数字+ミニ進捗の統一タイルコンポーネントにする。

### ビジュアル
- ヒーロー数字は金額に応じて「12.3万円」要約表記を検討(タップでフル桁)。
- コーチメッセージは常設テキストをやめ、状態が良い/悪い時のみ1行で表示。

### 操作
- 「給与設定」リンクはヘッダー右上に置かず、その他メニューへ(ホームのヘッダーは共通 ScreenHeader に統一)。
- 月切り替え(MonthSwitcher)は維持。

## この画面から出て行く情報
- 超過カテゴリの明細リスト → 予算画面
- 貯蓄目標の編集リンク・メッセージ詳細 → 目標設定画面
