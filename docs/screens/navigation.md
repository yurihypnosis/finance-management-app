# ナビゲーション・共通シェル — 改善戦略

## 対象
Topbar / BottomNav / ドロワーメニュー / ScreenHeader(新設)/ 画面間の導線

## 現状の問題
- 画面タイトルとナビラベルが全画面で不一致(「支出予測」⇔「支出」等)。
- ドロワーには残り物5画面(習慣/年間/投資/給与)+設定2つが雑多に並び、分類がない。
- 画面ヘッダーの作りが3方式混在(screen-title+sub / hdr-row / row-flex 独自)。
- 設定系画面(給与設定・目標設定)への導線が画面ごとにバラバラ(右上テキストリンク・メニュー・画面内リンク)。
- Topbar の「KAKEIBO」ロゴは常時表示だが情報価値が低く、縦スペースを消費。

## 改善戦略

### ラベルと構造
1. **名称の完全統一**: 画面タイトル=ナビラベル=メニューラベル。正式名は短い方に寄せる(支出/予算/レポート/習慣/年間/投資/給与)。
2. **ドロワーの再編**(BottomNav 4+その他 は維持):
   - 分析: レポート※ / 年間
   - 計画: 投資 / 習慣
   - 収入: 給与
   - 設定: 目標の設定 / 給与・賞与の設定 / ログアウト
   (※レポートはBottomNavにもあるがメニューからも到達可で良い)
3. **ScreenHeader コンポーネント新設**(Phase 1): タイトル+戻る矢印(設定系)+右アクション(編集アイコン等)を全画面で統一。既存3方式を置き換える。

### Topbar
- ロゴ行は薄く・低くする、または ScreenHeader に統合して1段にする(縦スペース回収)。
- 保存インジケータは現仕様(実データ変更時のみ表示)を維持。エラー時のみ目立たせる。

### 遷移・操作の統一ルール
- 設定系画面へは「編集アイコン(ScreenHeader右)」からのみ。本文中のテキストリンク導線(「目標を編集」「給与設定」)は原則廃止。
- 追加操作は各画面下部の統一「+」アクション、編集は行タップ→ボトムシート、削除はシート内(二度押し確認は維持)。
- タップ可能要素は最低44px。`link-quiet` の小リンクをタップ対象にしない。

## Phase 1 で先に作るもの
- ScreenHeader / ボトムシート / 統一「+」アクションの3部品(全画面がこれに依存するため最優先)
