# 習慣・固定費見直し — 画面別改善戦略

## この画面が答える質問
**「やめたら・減らしたら、いくら浮く?」**

## 現状の問題
- 画面名「習慣トラッキング」とナビ「習慣」が不一致。タブ「固定費見直し」の中身はサブスク管理で、支出画面の「固定費」タブと名前衝突。
- 習慣行に編集input+トグル+月換算input+年換算+メッセージ+削除が同居し、1行の情報量が過大。
- サブスク行は料金サイクル2択+活用度4択の計6ピルが並び、選択肢の羅列で圧迫感。ピルのタップ領域も小さい。
- 「未活用サービスの合計」が赤の32px大数字(警告でない情報に警告色)。

## 改善戦略

### 情報の階層
1. **ヒーロー: 見直しで浮くお金** — 「OFFにした習慣+未活用サブスク = 月◯円」を1つの大数字に統合し、この画面の成果を先頭で見せる。
2. **習慣タブ**: 1行 = 名前+頻度+月額+ON/OFFトグルのみの閲覧行。年換算・金額編集・削除はタップでシートへ。OFF行はグレーアウト+「月◯円節約中」だけ表示。
3. **サブスクタブ(名称変更: 「サブスク」)**: 1行 = 名前+月額換算+活用度バッジ1つ。活用度・支払いサイクルの変更はタップでシート(そこで4択+2択を大きなボタンで)。低活用のものを上に並べ、行に「解約候補」バッジ。

### ビジュアル
- 節約可能額は green、通常の金額はニュートラル。red は使わない。
- 活用度はテキスト4択でなく色付きバッジ(高=green/中=ニュートラル/低=amber/未使用=red)で1個だけ表示。

### 操作
- 投資画面の削減プランに反映される旨は、各タブ先頭の1行キャプションに短く(現状の screen-sub 長文を圧縮)。

## この画面から出て行く情報
- 年換算・アドバイス文・削除 → 編集シート内
- 「明細から検出+手動登録。OFFで節約額が投資プランに反映」の説明 → 1行キャプションに短縮
