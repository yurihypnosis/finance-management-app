# 年間 — 画面別改善戦略

## この画面が答える質問
**「このペースだと1年でいくら使う? 手取りに収まる?」**

## 現状の問題
- 画面名「年間出費シミュレーション」とナビ「年間」が不一致。
- ヒーローが2つ(見込み+統計予測)並び、主役が曖昧。
- 「80%信頼区間」「標準偏差 ±◯円」「n=◯」がそのまま露出。カテゴリ別の「月 ◯円 ± ◯円(n=3)」リストは完全に専門家向け表示。
- 内訳リストは文字+2pxバーで、年間の構成比が視覚的に掴めない。

## 改善戦略

### 情報の階層
1. **ヒーロー: 年間支出見込み** — 1つに絞る。年間手取りに対する割合を太いバーで示し、「手取りの◯%・残り◯円」を1行で。
2. **予測レンジの翻訳** — 統計予測は「ブレを見込むと ◯◯万 〜 ◯◯万円」の1行サブテキストとしてヒーローに統合。信頼区間・標準偏差・カテゴリ別±は「計算の詳細」折りたたみへ。
3. **内訳の視覚化** — 「月額×12」リストを構成比の横棒(カテゴリ色付き・降順)に。行タップで月額・年額・算出根拠(note)をシート表示。

### ビジュアル
- 数字は万円要約を基本に(年間レンジで7桁のフル桁羅列を避ける)。
- 手取り超過時のみ red、収まっていれば green のステータス色。

## この画面から出て行く情報
- 統計用語(信頼区間・標準偏差・n)→ 折りたたみ「計算の詳細」
- 各行の算出根拠 note → 行タップの詳細シート
