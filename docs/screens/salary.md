# 給与(+給与設定) — 画面別改善戦略

## この画面が答える質問
**「手取りはいくらで、何にいくら引かれている?」**

## 現状の問題
- 画面名「給与と税金」とナビ「給与」が不一致。
- 手取り+控除5行+注記+賞与(控除内訳を「・」区切りで1行4項目)+節税テクニック4種が1画面に縦積み。特に節税セクションは読み物化している。
- 控除の内訳バーは6色に分かれているが2pxで凡例もなく、色と項目の対応が読めない。
- 給与設定が別画面(salarySettings)にあり、給与画面右上のリンクで行き来する構造が分かりにくい。

## 改善戦略

### 情報の階層
1. **ヒーロー: 今月の手取り** — 大数字+「額面◯円から −◯円」の1行。控除内訳は太い積み上げバー+色チップ付きリスト(健康保険/年金/雇用保険/所得税/住民税)で対応関係を自明に。
2. **賞与** — 1行=「夏のボーナス(6月)・手取り◯円」の閲覧行のみ。控除内訳4項目はタップで詳細シートへ。
3. **節税テクニック** — 独立セクションとして残すが、初期表示は「合計 ◯円/年 の節税余地」+項目名と要点1行(上限◯円 等)のみ。説明文・進捗バー・条件の但し書きは各項目タップで詳細シートへ。
4. 概算の前提(扶養なし・40歳未満等)の注記 → (i)アイコンで表示。

### 給与設定(salarySettings)の扱い
- 独立画面は維持(設定系はメニュー配下)。ただしスライダー(月収30〜120万・賞与0〜200万)は範囲外の値を入力できないため、**数値入力併用**に変更する。
- 給与画面からの導線は ScreenHeader 標準の編集アイコンに統一。

### ビジュアル
- 手取り=green、控除は muted 系で統一(red は使わない — 税金は「警告」ではない)。

## この画面から出て行く情報
- 賞与の控除内訳・節税の説明文・前提注記 → 詳細シート/(i)アイコン
