# 支出 — 画面別改善戦略

## この画面が答える質問
**「今月いくら使う見込みか、その内訳は?」**

## 現状の問題
- 画面名「支出予測」とナビ「支出」が不一致。
- 4タブ(固定費/流動費/資金移動/現金支出)+現金タブ内の「繰り返しパターン管理」で、1画面に5つの仕事が同居。210行と最大の画面。
- 資金移動・現金支出の概念説明の長文が常時表示される。
- 資金移動・現金支出タブはリスト行が常時編集input(名前・メモ・金額・日付)で、閲覧時のノイズと誤タップ源。
- 「現金支出の合計」が赤の32px大数字 — 警告ではない情報に警告色。

## 改善戦略

### 情報の階層
1. **ヒーロー: 月末の着地予測** — 唯一の大数字。支出目標との比較は太い進捗バー+「目標まであと◯円」1行に統合。
2. **タブ再編(4→2+補助)**:
   - **「内訳」タブ**: 固定費・流動費を1つのリストに統合し、グループ見出し(固定/変動)+カテゴリ色チップで区別。閲覧専用。
   - **「現金・その他」タブ**: 現金支出と資金移動をここに集約。件数バッジは維持。
   - 繰り返しパターン管理は「現金・その他」内の折りたたみセクション(初期は閉)へ。
3. **説明文の撤去** — 資金移動/現金支出の概念説明は初回のみ or (i)アイコンタップで表示。常時表示しない。

### ビジュアル
- 着地予測に対する「使用済み/残り見込み」を太いバーで表現。
- 資金移動は緑・現金支出はニュートラル(fg)の数字。赤は超過時のみ。

### 操作(閲覧・編集の分離)
- 資金移動・現金支出の行を閲覧行に変更。行タップ → ボトムシートで編集・削除。
- 追加は画面下部固定の「+」アクション(FAB or 固定フッターボタン)に統一。

## この画面から出て行く情報
- 概念説明の長文 → ヘルプ(infoアイコン)
- 「カード請求額◯円」等の但し書き → 詳細シート内へ
