# 予算・ライフイベント — 画面別改善戦略

## この画面が答える質問
**「どのカテゴリが危ない?(予算タブ)」「積立は予定どおり?(ライフイベントタブ)」**

## 現状の問題
- 画面名「予算とライフイベント」とナビ「予算」が不一致。
- 予算リストの全行が常時編集input(カテゴリ名・実績・予算の3フィールド)。閲覧したいだけの画面で最も編集ノイズが激しい。
- 進捗バーが2pxで「どこが危ないか」が一目で分からない。カテゴリの色分けなし。
- ライフイベント行は1行に5つの編集フィールド(名前/時期/積立済/目標/月額)が詰まる。
- 「実績を入力・予算はタップして編集」という説明文で操作を補っている(UIが自明でない証拠)。

## 改善戦略

### 予算タブ
1. **サマリー先頭表示**: 予算総額に対する使用率を太いバー+「超過◯件」で先頭に。危ないカテゴリ順(使用率降順)に並べ替え。
2. **閲覧行の再設計**: カテゴリ色チップ+名前+太い進捗バー+「実績/予算」の1行構成。バー色で状態表現(〜80% ニュートラル / 80-100% amber / 超過 red)。
3. **編集の分離**: 行タップ → ボトムシートで実績・予算・名前を編集、削除もシート内。実績のクイック入力(今月の金額だけサッと入れる)はシート最上部に置いて1タップで到達。
4. カテゴリ追加は画面下部の統一「+」アクション。

### ライフイベントタブ
1. 1イベント=1カード(名前・時期・進捗リング or バー・「月◯円積立中」)の閲覧表示。
2. 編集(積立済/目標/月額/通貨)はタップでシートへ。為替の但し書きはシート内。
3. 先頭に「月の積立合計◯円」のサマリー1行。

### ビジュアル
- カテゴリ色パレット(Phase 1 で定義)をここが最初に使う。以後レポート・ホームと同じ色で通す。

## この画面から出て行く情報
- 操作説明文(「実績を入力・予算はタップして編集」)→ UI 自体で自明にして削除
- 為替換算の説明 → 編集シート内
